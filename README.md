
# Student Grade Calculator

## Project Overview
The Student Grade Calculator is a simple Python application that calculates the average marks of a student and determines the grade.

## Folder Structure
- src/ - Contains the main application code.
- tests/ - Contains testing scripts.
- docs/ - Contains project documentation.
- assets/ - Stores images and other resources.

## Features
- Accepts student marks.
- Calculates average marks.
- Displays the student's grade.
